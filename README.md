# Netflix Content Strategy Analysis

## Project Overview
This project analyzes Netflix content using Python and data visualization techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Movies dominate Netflix content.
- Content growth increased significantly after 2015.
- USA and India contribute the most content.
- Drama is one of the most popular genres.
